# 切換 Windows 使用的 Microsoft 帳戶
# Switch the Microsoft Account Used in Windows

## 中文

### 應用場景

打開 Windows 的帳戶設定後，發現目前登入的是不想使用的 Microsoft 帳戶，而不是本機帳戶。你想先切換成「本機帳戶」，再登入自己的 Microsoft 帳戶。

### 操作步驟

#### 1. 切換成本機帳戶

1. 按下 **`Windows + I`** 開啟「設定」。
2. 選擇 **「帳戶」→「您的資訊」**。
3. 在「帳戶設定」附近，選擇 **「改用本機帳戶登入」**。
4. 依照畫面提示確認身分。系統可能要求輸入目前 Microsoft 帳戶的密碼或其他驗證資訊。
5. 設定本機帳戶的使用者名稱和密碼。若不打算設定密碼，請依畫面提示留白；若系統要求密碼，則需依照提示完成。
6. 選擇 **「下一步」**，再選擇 **「登出並完成」**。
7. Windows 登出後，回到登入畫面。使用剛才設定的本機帳戶登入。

> **說明：**「本機帳戶」是存在這台電腦上的帳戶，不等於一定是購買電腦時設定的管理員帳戶，也不保證具有管理員權限。請依照畫面設定或確認本機帳戶資訊；不要假設舊帳戶沒有密碼。

#### 2. 登入自己的 Microsoft 帳戶

1. 使用本機帳戶登入 Windows 後，再按 **`Windows + I`** 開啟「設定」。
2. 選擇 **「帳戶」→「您的資訊」**。
3. 選擇 **「改用 Microsoft 帳戶登入」**。
4. 輸入你自己的 Microsoft 帳戶電子郵件地址和密碼，並依照畫面完成驗證。
5. 按照提示完成設定；Windows 可能會詢問是否設定或使用 Windows Hello PIN。
6. 完成後，Windows 帳戶會切換為你的 Microsoft 帳戶。

### 注意事項

- Windows 版本或組織管理設定不同時，畫面文字可能略有差異。
- 切換 Windows 登入帳戶，不一定會自動登出 OneDrive、Microsoft Store 或其他 Microsoft 應用程式；如有需要，請分別檢查這些應用程式的登入狀態。
- 如果找不到「改用本機帳戶登入」或「改用 Microsoft 帳戶登入」，目前帳戶狀態或電腦管理政策可能不允許切換。請確認電腦是否由公司或學校管理。

## English

### When to use this guide

You open Windows account settings and find that Windows is using a Microsoft account you do not want to use. You want to switch to a local account first, then sign in to Windows with your own Microsoft account.

### Steps

#### 1. Switch to a local account

1. Press **`Windows + I`** to open **Settings**.
2. Select **Accounts → Your info**.
3. Under **Account settings**, select **Sign in with a local account instead**.
4. Follow the prompts to verify your identity. Windows may ask for your current Microsoft account password or other verification information.
5. Set a username and password for the local account. If you do not want to set a password, leave the password fields blank only if the screen allows it. If Windows requires a password, follow the prompts.
6. Select **Next**, then select **Sign out and finish**.
7. After Windows signs you out and returns to the sign-in screen, sign in with the local account you just set up.

> **Note:** A local account is an account stored on this PC. It is not necessarily the administrator account created when the PC was first set up, and it is not guaranteed to have administrator privileges. Follow the on-screen prompts and use the correct account information; do not assume the previous account has no password.

#### 2. Sign in with your Microsoft account

1. After signing in to Windows with the local account, press **`Windows + I`** to open **Settings**.
2. Select **Accounts → Your info**.
3. Select **Sign in with a Microsoft account instead**.
4. Enter the email address and password for your own Microsoft account, then complete any verification steps.
5. Follow the prompts to finish setup. Windows may ask you to set up or use a Windows Hello PIN.
6. When setup is complete, your Windows account will be switched to your Microsoft account.

### Notes

- The wording and layout may vary slightly depending on your Windows version or organization settings.
- Switching the Windows sign-in account does not necessarily sign you out of OneDrive, Microsoft Store, or other Microsoft apps. Check those apps separately if needed.
- If you cannot find **Sign in with a local account instead** or **Sign in with a Microsoft account instead**, the account status or device-management policy may prevent switching. Check whether the PC is managed by a work or school organization.
